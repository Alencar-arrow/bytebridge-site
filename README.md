### 🚀 Sobre o Projeto
O **ByteBridge** é um site interativo desenvolvido como apresentação visual e institucional em slides para a empresa do Trabalho de Conclusão de Curso (TCC). A aplicação combina estratégia e tecnologia para apresentar os serviços da empresa, software sob medida, portfólio e proposta de valor de forma dinâmica.

---

### 💻 Tecnologias Utilizadas
- **HTML5** — Estruturação semântica das seções e navegação.
- **SCSS (Sass)** — Pré-processador CSS avançado para estilização modular, uso de variáveis e organização em cascata.
- **JavaScript** — Manipulação do DOM para o funcionamento fluido do carrossel interativo de slides.

---

### ✨ Funcionalidades
* **Hero Section Impactante:** Mensagem de destaque com chamada para ação (*Inicie seu projeto*).
* **Navegação Intuitiva:** Links rápidos para as seções *Quem somos*, *Serviços* e *Portfólio*.
* **Carrossel Interativo:** Transição dinâmica entre slides e blocos de conteúdo controlada via JavaScript.
* **Identidade Visual Personalizada:** Utilização de vetores em SVG e paleta moderna em tons de laranja, preto e bege.
